## 测试方法与复现

隔离原游戏 PCK、独立游戏进程和测试存档，加载真实 Online ZIP 与构建的补丁 ZIP，通过前置的真实 LAN 会话连接 `127.0.0.1`。使用 `Input.parse_input_event` 注入鼠标移动、按下、释放、滚轮以及键盘输入，坐标使用当前视口变换；具体按钮操作沿用游戏及前置原信号。

测试设置确定的货币、奖励和解锁条件，以稳定复现操作。建房、加入及奖励搭建属于测试准备；不把直接调用菜单操作或同步入口算作鼠标通过。独立进程之间的测试文件只传递屏障和只读权威观察数据。

```powershell
python tools/build_mouse_ui.py
python tools/run_mouse_ui_tests.py --game-dir 'D:/Program Files (x86)/Steam/steamapps/common/Brotato' --case all --timeout 150
```

原始结果：`.local/mouse-ui-tests/20260918-200150-742ed1cc/summary.json`，各组合下有每个进程的 JSON、日志和截图。测试使用独立 `BrotatoMouseUITests-*` 存档目录，没有读取或修改正常游戏存档。
